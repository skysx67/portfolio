## Исправление якорей и анимаций

Ранее показ зависел только от IntersectionObserver с отрицательным нижним
отступом и задержками; у масок наблюдался родитель, который тоже мог быть
внутри скрытой маски. Отдельного раскрытия целевого hash не было. Страховочный
таймер ожидал событие `load`, поэтому медленная загрузка ресурсов откладывала его.

Теперь CSS `:target` сразу раскрывает содержимое целевой секции. Обработчики
клика, `hashchange` и первоначального hash сохраняют это состояние через
`.rv-direct` и `.rv-in`, включая вложенные заголовки и фотографии.
`scroll-margin-top: 88px` оставляет место под липкую шапку.

Наблюдаемые узлы выбираются вне закрытых масок; положительный нижний отступ
раскрывает контент заранее. Первое окно показывается при инициализации,
задержка лесенки ограничена тремя шагами. Если основной скрипт не готов,
через 1,2 секунды скрывающие состояния снимаются без ожидания `load`.
Анимации при обычной прокрутке сохранены. Без JS основное содержание видно;
при reduced-motion скрытие, задержки и декоративный курсор отключаются.

  Публикация и `git push` не выполнялись; для них требуется отдельное подтверждение владельца.
