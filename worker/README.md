# Приватные уведомления о рекомендациях

Cloudflare Worker принимает только код рекомендателя и тип действия. Имена,
телефоны и текст формы через него не отправляются. Токен Telegram и `chat_id`
хранятся в Secrets на стороне Cloudflare и никогда не попадают в GitHub Pages.

Нужны два секрета:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

После публикации URL Worker указывается в `LEAD_ENDPOINT` внутри
`assets/js/app.js`. До этого сайт продолжает работать по старой безопасной
схеме с номером обращения в подготовленном сообщении.
