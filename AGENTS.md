# Рабочий процесс

По указанию владельца проекта готовые изменения после необходимых проверок
нужно автоматически коммитить и пушить в GitHub без отдельного подтверждения.
В коммит включать файлы текущей задачи; посторонние незавершённые изменения
оставлять нетронутыми. Не использовать force push без явного указания.
