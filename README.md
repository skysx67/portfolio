# Портфолио + 4 демо-лендинга

Статический сайт-портфолио и три демо-лендинга к нему. Без сборки, без зависимостей —
чистые HTML/CSS/JS. Открывается двойным кликом по `index.html`, публикуется как есть.

## Структура

```
.
├── index.html              портфолио (главная)
├── assets/
│   ├── css/style.css       стили портфолио
│   ├── js/app.js           меню + форма
│   └── img/                скриншоты кейсов и фото
├── demo/
│   ├── remont/             «Ровно» — ремонт квартир, калькулятор сметы
│   ├── potolki/            «Потолок72» — натяжные потолки, прайс
│   └── design/             «Северова» — дизайн интерьера, квиз на стиль
├── CREDITS.md              откуда фото и шрифты
└── .nojekyll               чтобы GitHub Pages не трогал файлы
```

Четвёртый кейс — действующий сайт мебельной компании
[Перфекто](https://skysx67.github.io/perfecto-mebel/), он живёт в отдельном репозитории
и подключён к портфолио внешней ссылкой.

## Демо-сайты

Каждый лендинг сделан со своим визуальным языком, а не перекрашен из общего шаблона:

| Сайт | Ниша | Язык дизайна | Главная фишка |
|---|---|---|---|
| `demo/remont` | Ремонт под ключ | «инженерный»: сетка-миллиметровка, моношрифт, жёсткие углы, жёлтый акцент | калькулятор сметы с разбивкой и сроком |
| `demo/potolki` | Натяжные потолки | светлый и быстрый: электрик-синий, крупные скругления, мягкие тени | прайс и готовые цены по комнатам |
| `demo/design` | Дизайн интерьера | редакционный: антиква, острые углы, песочно-графитовая палитра | квиз «какой стиль вам подойдёт» на 5 вопросов |

Компании вымышленные, телефоны нерабочие (`00-00-00`), формы ничего не отправляют —
показывают «Спасибо, заявка отправлена» и на этом всё. На каждой странице сверху
висит плашка «Демо-проект» со ссылкой обратно в портфолио.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если нужен полноценный сервер
(например, чтобы проверить относительные пути так же, как на хостинге):

```bash
python -m http.server 5173
```

Дальше `http://localhost:5173`.

## Публикация на GitHub Pages

```bash
git add -A && git commit -m "Портфолио и демо-лендинги"
git push -u origin main
```

Затем в настройках репозитория: **Settings → Pages → Source: Deploy from a branch →
Branch: `main` / `(root)`**. Через минуту сайт доступен по адресу
`https://<логин>.github.io/<репозиторий>/`.

Все пути внутри проекта относительные, поэтому сайт одинаково работает и в подпапке
GitHub Pages, и в корне своего домена — при переезде ничего править не нужно.

## Что где менять

Все личные данные лежат только в `index.html`:

- имя — 4 места: `<title>`, шапка, блок «Обо мне», подвал
- Telegram — ссылка `https://t.me/...` и её текст в блоке контактов
- телефон — `href="tel:..."` и его текст рядом

В блоке «Что делаю» есть строка про скидку первым клиентам, она помечена
комментарием `<!-- Убрать этот блок, когда первые клиенты появятся -->`.

Цены (15/25/35 тыс.) и все цены внутри демо-лендингов — прикидка, а не факт.

## Что ещё стоит сделать потом

- Свой домен вместо адреса GitHub Pages.
